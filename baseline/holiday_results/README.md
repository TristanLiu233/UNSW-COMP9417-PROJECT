# NSW 公共假期对需求预测的影响

Ridge 比较原有 25 列与 26 列，梯度提升回归比较原有 29 列与 30 列。每一对只追加 `is_nsw_public_holiday`，保持相同的样本、顺序、估计器参数和随机种子。该列取课程指定 `holidays==0.107` 中澳大利亚 NSW 的公共假期（含补休日），每个市场日的 48 档共享一个 0/1 值。

## 2014 年选型

用 2010-01-29 至 2013-12-31 的 68,784 档训练，在 2014 年的 17,520 档验证。全年共 365 天，含 11 个公共假期。下表每个箭头的左侧为原配方，右侧为加假期列后的成绩，两个指标均越低越好。

| 模型 | 全年 MAPE | 全年 MAE（MW） | 假期 MAPE | 非假期 MAPE |
| --- | ---: | ---: | ---: | ---: |
| Ridge | 3.3093% → 3.2310% | 262.65 → 257.08 | 9.8516% → 6.1267% | 3.1060% → 3.1411% |
| 梯度提升回归 | 2.4355% → 2.3318% | 192.50 → 185.27 | 7.8748% → 3.7784% | 2.2665% → 2.2869% |

沿用原消融选型标准：按全年 MAPE 选较低者；差距在 0.05 个百分点以内且配对整日区间包含零时，选较少字段。两个模型按此规则均入选含假期的配方。以“加假期减原配方”计算，Ridge 全年差值为 −0.0782 个百分点，95% 区间为 [−0.2075, +0.0452]，改善幅度仍有不确定性。梯度提升回归差值为 −0.1037 个百分点，区间为 [−0.2127, −0.0059]。区间按整市场日做 2,000 次配对自助抽样，种子为 17。[精确分组结果](metrics.csv)

## 2015 年 1 月至 2026 年 10 月冻结回测

两种配方分别用截至 2014 年底的 86,304 档重训。固定各自权重，在随后的 4,322 天（207,456 档）评估，其中 141 天为公共假期。保留 2014 年的选型决定。

| 模型 | 全期 MAPE | 全期 MAE（MW） | 假期 MAPE | 非假期 MAPE |
| --- | ---: | ---: | ---: | ---: |
| Ridge | 5.0100% → 5.0398% | 383.13 → 385.48 | 9.1087% → 7.8649% | 4.8718% → 4.9445% |
| 梯度提升回归 | 4.4230% → 4.3452% | 315.30 → 309.35 | 7.9110% → 5.5664% | 4.3054% → 4.3040% |

梯度提升回归的长期 MAPE 下降 0.0779 个百分点，配对整日 95% 区间为 [−0.1026, −0.0534]。Ridge 在假期的误差降低，但非假期更多，全期 MAPE 上升 0.0298 个百分点，区间为 [−0.0039, +0.0628]。进一步训练主需求模型时，证据支持将假期标记追加到梯度提升回归的 29 列之后。原基线模型文件保留其消融配方。[精确分组结果](frozen_metrics.csv)

## 复现与回滚

在仓库根目录、课程环境中依序运行。程序核对实际参与运算的库版本。本次使用 Python 3.11.13、NumPy 2.4.6、pandas 3.1.0、SciPy 1.17.1、scikit-learn 1.9.1、joblib 1.6.0 和 holidays 0.107，拟合和评估均为单数值线程。

```shell
python -m baseline.holiday_ablation --data "data/nem_weather_halfhourly_2010_2026.csv"
python -m baseline.holiday_ablation --data "data/nem_weather_halfhourly_2010_2026.csv" --frozen
```

默认模式输出 2014 年的 `metrics.csv`，冻结模式输出 `frozen_metrics.csv`。两次运行都只写实验指标；权重在内存中训练。使用 `--output` 可以把一次复跑的成绩放入其他目录。
