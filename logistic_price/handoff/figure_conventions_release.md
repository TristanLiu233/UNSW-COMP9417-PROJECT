# P4 figure conventions
Released on 16 November 2026. Use the [P4 figure conventions](../notes/figure_conventions.md) when preparing or compiling figures. That document sets the units, date coverage, confidence intervals, colours, axis labels, resolution and class-share exclusions for P4. The group can adopt the same conventions for its other figures. At release, this pointer had been prepared locally for sharing. Link to the source document when distributing it.
