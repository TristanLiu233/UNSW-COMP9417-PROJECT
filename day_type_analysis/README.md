# NSW 用电需求日型分析

## 1. 分析目标

根据 NSW 每天 48 个半小时的用电需求值识别典型日型。以 2010–2013 年为固定参照，观察后续年份的日型占比如何变化，以及同一日型的需求曲线在哪些时段发生了变化。

## 2. 运行方法与文件结构

在项目根目录运行：

```bash
python day_type_analysis/cluster_day_types.py
python day_type_analysis/analyze_day_type_changes.py
```

两份脚本都使用 `data/nem_weather_halfhourly_2010_2026.csv` 中的 `timestamp` 和 `nsw_demand` 两列。原始时间戳表示半小时区间的结束时间。划分市场日时先减去 30 分钟，因此午夜 `00:00` 的记录属于前一天最后一个时段。

以下路径相对于 `day_type_analysis/`。

| 文件或目录 | 用途 |
| --- | --- |
| `cluster_day_types.py` | 构造每日需求曲线，选择簇数，拟合最终 PCA 和 K-means，生成逐日日型标签、典型曲线图和年度占比图 |
| `analyze_day_type_changes.py` | 读取逐日日型标签和需求数据，分析两类日型到训练期簇中心的距离，并比较训练期与近期曲线 |
| `cluster_day_types_pca99.py` | 将 PCA 方差保留阈值提高至 99%，检查簇数选择是否随之变化 |
| `outputs/day_type_clustering/` | 留年验证评分表、逐日日型标签、典型需求曲线和年度占比 |
| `outputs/day_type_changes/centroid_distance/` | 两类日型各自的年度距离图、CSV 和两类合并汇总表 |
| `outputs/day_type_changes/profile_comparison/` | 同一日型在 2010–2013 年和 2024–2025 年的需求曲线对比图及 CSV |
| `outputs_loyo_pca99/` | PCA 99% 敏感性实验结果 |

## 3. 分析方法

### 3.1 为什么按当日均值归一化

将每一天的 48 个需求值分别除以当天的平均需求。归一化后，`1.00` 表示该日的平均需求水平，`1.20` 表示该时段的需求比当天均值高 20%。

本分析关注的是需求在一天内如何分布，例如午间低谷有多深、傍晚高峰有多突出。如果两天的需求曲线形状相同，只是其中一天每个时段的需求都高 20%，那么它的日均值也高 20%，两条曲线归一化后完全相同。只在某些时段发生的变化仍然保留，因此这种表示适合比较日内形状。

归一化移除了绝对需求规模。逐日日型标签表保留 `daily_mean_mw`，供后续单独分析绝对用电水平。

### 3.2 PCA 与簇数选择

主分析采用 PCA 降维和 K-means 聚类。将 PCA 的累计解释方差阈值设为 95%，在 2010–2013 年内部轮流留出一个完整年份，比较 `k = 2–10`。

每轮用另外三年拟合 PCA 和 K-means，再用该轮的 PCA 和簇中心给留出年份分配日型。根据四轮留出年份的平均轮廓系数选择 `k`。轮廓系数越高，表示按该距离度量，簇内样本更接近、簇间区分更明显。

| 候选簇数 | 四轮平均轮廓系数 | 四轮标准差 |
| --- | ---: | ---: |
| `k = 2` | **0.4110** | 0.0119 |
| `k = 5`（第二名） | 0.3374 | 0.0203 |
| `k = 3` | 0.3068 | 0.0351 |

`k = 2` 在四个留出年份中都排名第一。将 PCA 方差阈值提高至 99% 后，四轮验证仍然选出 `k = 2`。主分析使用 95% 阈值。

### 3.3 固定训练期参照

选定 `k = 2` 后，用完整的 2010–2013 年共 1,461 天拟合最终 PCA 和 K-means。最终 PCA 保留 5 个主成分，解释训练期方差的 96.24%。

从 2014 年起，每天用固定的 PCA 转换，再分到最近的固定簇中心。年度日型占比的分母为当年的观测天数。年度统计纳入所有可用月份，2026 年数据截至 10 月 31 日。

### 3.4 如何衡量日型变化

- **簇中心距离。** 在 PCA 空间计算每天到其所属训练期簇中心的欧氏距离，按年、按日型统计距离中位数、P90（第 90 百分位数）以及超过本类训练期 P90 的比例。训练期 P90 是本分析选用的描述性参考线。
- **分时期需求曲线。** 对每个日型比较 2010–2013 年与 2024–2025 年。选择 2024–2025 年是因为这两年是数据中最近的两个完整日历年。实线表示各半小时档位的归一化均值，阴影表示同一档位跨观测日的 P10–P90 范围。

## 4. 分析结果

### 4.1 训练期典型日型与年度占比

| 日型 | 2010–2013 年的典型形状 | 2010–2013 年合计 | 2025 年 | 2026 年截至 10 月 31 日 |
| --- | --- | ---: | ---: | ---: |
| **Type 1** | 早晨需求上升，午间回落，傍晚高峰更突出 | 794 天（54.3%） | 360 天（98.6%） | 304 天（100%） |
| **Type 2** | 白天需求持续处于相对较高水平，曲线较平坦 | 667 天（45.7%） | 5 天（1.4%） | 0 天（0%） |

按固定簇中心分配，Type 1 在后期占绝大多数。2026 年占比对应截至 10 月 31 日的观测期。

### 4.2 Type 1 的形状变化

2018 年，Type 1 的年度距离中位数首次超过它的训练期 P90（0.3362）。到 2025 年，360 个 Type 1 日期中有 344 天（95.6%）超过这条参考线。Type 1 仍是这些日期最近的训练期簇中心，但后期许多日期的需求曲线形状已经和训练期典型的 Type 1 相差较大。

比较 2010–2013 年和 2024–2025 年，12:00 的平均归一化需求从日均的 **1.03 倍**降至 **0.81 倍**，18:00 从 **1.18 倍**升至 **1.27 倍**。相对于各自当天的平均需求，近期 Type 1 的**午间低谷更深，傍晚高峰更突出**。

### 4.3 Type 2 的形状变化

2024–2025 年只有 20 天被分到 Type 2。这些日期的平均需求曲线比 2010–2013 年的 Type 2 曲线更偏向下午高峰。2025 年的 5 个 Type 2 日期均超过本类训练期 P90（0.3720）。近期样本量很小，解读时应同时给出天数。2026 年观测期内 Type 2 有 0 天，距离统计留空。

### 5.2 待完成的预测误差与输入漂移对照

- **预测误差。** 将冻结需求模型的逐日误差按 `market_day` 与 `day_type_assignments_loyo_k2_pca95.csv` 对齐。如果拿到的是半小时预测，先按时间戳匹配真实需求，再按市场日匹配日型。在共同评估期内报告逐年日型占比、整体误差、分日型误差和对应样本数，分析占比变化与误差上升是否同期出现，以及同一日型内的误差是否也在上升。
- **输入漂移。** 按组内检测器的时间窗口汇总日型占比和簇中心距离，与输入漂移告警的日期对照。报告中说明哪些变化同期出现，哪些时间点存在差异。
- **日型标签的可用时间。** 本分析的标签由当天完整的真实需求曲线计算，适用于事后误差分析。发出 D+1 预测时，D+1 的真实日型尚不可用。

## 6. 相关研究

Afzalan 等人（2021）用两阶段聚类提取具有代表性的家庭用电曲线，为解释典型曲线提供了背景。本项目采用的是 PCA 加 K-means，并在 2010–2013 年上建立固定参照。

Jessen 等人（2022）对印度尼西亚龙目岛的半小时用电曲线应用 K-means，研究与供电扰动相关的异常模式。该研究为使用聚类分析用电曲线偏离提供了背景。本项目用到固定训练中心的距离描述 NSW 日需求形状的变化。
