# NSW 日前预测的三轮特征消融

组员接手训练时可直接使用[消融说明](消融说明.md)，其中回归组和分类组各有两份独立的有序列清单、训练参数及可执行示例。

在仓库根目录、课程 Python 3.11 环境运行下列命令。`--data` 指向课程发布的 CSV；若文件已放在仓库 `data/` 下的默认位置可省略该参数。`--jobs 1` 可顺序执行，默认同时运行两个模型。

```shell
python -m ablation.run --data "path/to/nem_weather_halfhourly_2010_2026.csv"
```

仓库已包含[2014 验证年的结果摘要](RESULTS.md)和[原版离线 HTML](outputs/2014-ablation-matrices/消融矩阵.html)。例如，已激活课程环境并把发布数据放在仓库 `data/` 目录时，可运行：

```powershell
python -m ablation.run --data 'data/nem_weather_halfhourly_2010_2026.csv' --jobs 3 --threads 1
```

## 样本、算法和指标

每个目标市场日一次预测 48 档，以半小时区间起始日期归属市场日。历史市场数据截止目标日 00:00。仅从原文件读取到 2015-01-01 00:00（2014 年最后一档），共同预热 28 天后，训练期为 2010-01-29 至 2013-12-31，共 68,784 档；验证期为 2014 年 17,520 档。脚本按官方实现逐日核对标签及昨日、上周两条基线，并在年首、年中和年末截断未来数据、替换预测日六列市场观测，检查特征一致性。

| 模型标识 | 模型与固定参数 | 训练目标 | 主指标 / 辅助指标 |
|---|---|---|---|
| `ridge` | 标准化＋Ridge，α=1 | 平方误差＋L2 | MAPE / MAE (MW) |
| `boost_demand` | 直方图梯度提升树，100 棵、31 叶、学习率 0.1 | 平方误差 | MAPE / MAE (MW) |
| `logistic` | 标准化＋L2 逻辑回归，C=1 | 二元交叉熵＋L2 | 平衡准确率 / 准确率、两类召回率 |
| `boost_price` | 同结构的直方图梯度提升树 | 二元交叉熵 | 平衡准确率 / 准确率、两类召回率 |

前三轮固定超参数、样本及分类概率阈值 0.5。分类真值始终按该档 NSW 电价是否**严格大于昨日原始均价**计算。所有时期的平衡准确率先拼接该时期的半小时，再按出现类别计算平均召回率。

## 三轮怎样比较

1. **信息来源。** `C` 含日历、档位、NSW 需求与电价的昨日和上周同档值、昨日原始均价与同档价差。`CW` 在 C 上增加悉尼温度、湿度、云量和辐射；`CR` 增加 QLD/VIC 需求与电价的昨日、上周同档值；`F` 同时加入两组。除逐组成对比较，还报告 `F−CW−CR+C` 的交互差值。
2. **具体维度。** 各模型都检验四个悉尼天气字段，还按州、需求/价格、州×变量、单一滞后列拆解八个邻州字段。每个维度做三次对照：单独加入 C、从所在信息组移除、从 F 移除。`retain_in_…` 的差值统一为**含该维度减去移除该维度**，便于与 `add_alone_…` 对照。即使整个信息组表现较差，也测试其成员。组合筛选保留在“单独加入”或“在 F 中保留”至少一种情况下使 MAPE 降低超过 0.05 个百分点或 BA 提高超过 0.5 个百分点的单列，并将它们一起重跑 (`dimension_mix`)。这些界限是实验取舍。贡献随参照和算法而变，不作因果解释。
3. **构造方式。** 从每个模型在前两轮入围的输入 `anchor` 出发，比较去掉全部上周同档列、加入 7/28 个历史完整日同档均值与标准差、加入墨尔本和布里斯班天气。回归另试昨日需求日型（用训练日按日均归一的 48 档曲线，PCA 保留 95% 方差，固定四个 KMeans 中心）；分类另试去掉显式价格差、加入昨日最高价和负价档数。每类改动保留一个选择，实际重跑 `combined`，再撤回每个入选改动及所含天气/邻州单列。结果仅代表测试过的有限组合。

**公平调参。** 独立于上述固定参数对照，对四个首轮信息组以及每个算法选出的固定参数入围组合，在 2013 上、下半年两个扩展时间折内分别调参。每种输入尝试三档模型参数；两个分类器使用同一组概率阈值 0.40–0.60，间隔 0.05。每折的标准化、日型 PCA 和聚类均只在该折的训练历史上拟合。按两折拼接的样本外预测选定参数，再用全部训练数据重拟合、评估 2014 年。`tuned_…` 与未经调参的对照分别报告。

**选型与不确定性。** 需求取较低的 MAPE，价格取较高的平衡准确率；与点估计最佳者相差不超过上述界限、且配对整日 95% 差值区间含零时，优先较少字段。对每组计划对照用 2,000 次配对整日抽样，同时给出连续 7 日块的敏感性区间。多组比较和选型共用 2014 年，报告的区间不校正重复挑选；选中的构造尚待冻结历史回放检验。

## 输出在哪里

默认保存在 `ablation/results/`，表内的 `config` 可与相应模型的预测文件列名直接关联。

[交互消融矩阵](outputs/2014-ablation-matrices/消融矩阵.html)可逐格查对照与区间；[Excel 工作簿](outputs/2014-ablation-matrices/消融实验矩阵.xlsx)支持按算法、阶段、配置和字段筛选；[维度热图](outputs/2014-ablation-matrices/维度消融热图.png)展示全部 240 个维度贡献。用 `python -m ablation.render_matrices` 可从本地结果表及 12 行补充天气对照重新生成 HTML。

| 输出 | 可回答的问题 |
|---|---|
| `scores.csv` | 每个算法、每种构造具体用了哪些字段、多少样本、什么参数，各项指标及与两条基线的差值是多少？ |
| `contrasts.csv` | 只改一个因素时，指标差是多少？`delta_pp` 为候选减参照；MAPE 负值和 BA 正值表示改善。`day_*`、`week_*` 为两种 95% 差值区间。 |
| `tuning.csv`、`selection.csv` | 每种配置在 2013 两个时间折的得分、选定参数，以及各算法最终在 2014 入围的构造与完整列清单是什么？ |
| `task_winners.csv`、`final_comparisons.csv` | 两个任务各选中的算法和具体输入，以及它对另一家族和两条官方基线的配对差值及区间。 |
| `validation.csv.gz`、`predictions/*.csv.gz` | 每档真实值、官方基线、所有消融模型当时给出的需求或 0/1 分类预测是什么？文件按时间戳对齐。 |
| `baselines.csv`、`run.json` | 两条官方基线、版本、训练/验证范围、数据前缀校验值、种子和运行设置。 |
